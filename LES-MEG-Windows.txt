FullPeiling Møtereferat for Windows 0.1.2 (pilot)

Installer FullPeiling-Motereferat-Windows-0.1.2.exe på Windows x64. Støttet målplattform er Windows 11 25H2 (bygg 26200) eller nyere. Windows 11 24H2 er teknisk installasjonsgrense og regnes ikke som støttet plattform. ARM er ikke kvalifisert. Installasjonen skjer for din bruker uten administrator, og appen har egen identitet og datamappe ved siden av Automagisk. Har du 0.1.1 fra før, kan 0.1.2 installeres over den. Oppgraderingen er ikke prøvd på en fysisk PC.

Filen er usignert, så Windows kan varsle om ukjent utgiver. Kontroller filnavn, nedlastingssted og SHA-256 før du installerer, og følg bedriftens sikkerhetsregler dersom Windows blokkerer installasjonen.

Ved første start logger du inn med e-post eller Microsoft og godtar behandlingen. Møtelyden lagres kryptert på PC-en. Du trenger ingen talemodell, egen AI-konto eller nøkkel. Kjør første forsøk med et ufølsomt testopptak.

Pilot: referatet er foreløpig bare tilgjengelig for inviterte kontoer. Andre kan installere og ta opp, men får ikke referat ennå.

Nytt i 0.1.2: Du logger inn med e-postkode eller Microsoft, og godtar behandlingen én gang per konto. Referatet skrives for deg, med sammendrag, hovedpunkter, beslutninger, oppfølgingspunkter og åpne spørsmål, og kan kopieres eller eksporteres til PDF og Markdown. Du laster ikke ned talemodeller, og oppsettet har ikke lenger valg av modell eller leverandør. Et opptak som venter på innlogging, kan slettes, og appen kan lukkes mens det venter.

Kjent i 0.1.2: Innlogging, opptak og referat er prøvd på en Windows-PC med en testkopi som har de samme rettingene, ikke med denne installasjonsfila. Installasjon over 0.1.1 er ikke prøvd på en fysisk PC, og skjermleser er ikke prøvd.

Om denne versjonen: bygget be66198b0250e9657907bae09a173f7994c7b317 i CI-kjøring 39911329512 på Windows Server 2025, der alle jobbene og dommen var grønne. Piloten er til kontrollert utprøving, ikke en ferdig signert kundeutgivelse.

iCloud-synk med iPhone og automatisk oppdatering er ikke tilgjengelig i 0.1.2. Installer nye versjoner fra referat.fullpeiling.no. Appen er foreløpig ikke Microsoft-signert.
