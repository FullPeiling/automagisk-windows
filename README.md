# Automagisk for Windows

Her ligger utgivelsene av Automagisk for Windows, møtereferatdelen. Kildekoden ligger
ikke her. Les mer, og last ned siste versjon, på https://automagisk.app/windows.html.

Appen holder seg oppdatert selv: den ser etter en ny utgivelse her ved start, laster den
ned i bakgrunnen og tar den i bruk neste gang du starter appen.

Automagisk er laget av Appit AS, Bergen.
